# DR. Perla · Actualizaciones

Aquí se publican las versiones de **DR. Perla**, el programa para consultorios médicos.
Este repositorio no tiene el código fuente: solo los paquetes ya armados.

- **Instalar por primera vez:** descargue `DR-Perla-Instalador-<versión>.exe` de la carpeta [`versiones`](versiones).
- **Actualizar:** en DR. Perla, entre como superusuario de soporte → **Configuración → Actualizar DR. Perla → Buscar actualización**.
  Sin internet, lleve el archivo `.drpa` en una memoria USB y súbalo en esa misma pantalla.

Cada paquete `.drpa` va firmado. DR. Perla rechaza cualquier archivo que no tenga la firma del autor o que haya sido modificado.
